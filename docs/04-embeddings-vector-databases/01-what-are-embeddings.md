# 4.1 What are Embeddings

## Definition

Numeric vector representations of text (or images/audio) placed in a high-dimensional space such that semantically similar items are positioned close together. Generated by a dedicated embedding model, separate from the generative LLM you use for chat or completion.

## How similarity is measured

Embeddings are compared using distance metrics:
- **Cosine similarity** — angle between two vectors, most common for text
- **Dot product** — raw magnitude-weighted similarity
- **Euclidean distance** — straight-line distance in vector space

## Use cases

**Semantic search**
- Find documents by meaning, not exact keyword match
- "car troubles" retrieves a document about "vehicle maintenance issues" even with zero shared words

**Data classification**
- Cluster or categorize text based on vector proximity
- Group support tickets by topic without hand-labeling every one

**Recommendation systems**
- Recommend similar items/content based on embedding similarity
- "users who read this also read..." without collaborative filtering data

**Anomaly detection**
- Flag data points that lie far from normal embedding clusters
- Spot a fraudulent transaction description that doesn't resemble legitimate ones

## Why this matters for RAG

Embeddings are the mechanism that makes [RAG](../05-rag/01-what-are-rags.md) possible: you can't retrieve "the most relevant chunk" for a query without a way to mathematically compare meaning. Everything in [4.3 Vector Databases](03-vector-databases.md) exists to store and search these vectors efficiently at scale.
