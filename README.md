## Why this exists

Most "awesome AI" lists are just link dumps — hundreds of bookmarks with no structure, no depth, and no way to tell what actually matters. This repo is different:

- **`docs/`** — original, detailed notes on every concept in the AI Engineer track, written from scratch (definitions, comparisons, tables, glossaries), not copy-pasted from any course or book.
- **`resources/`** — the best free external resources for each topic, organized by category, so you know exactly where to go deeper.

Nothing here reproduces paywalled or copyrighted material. Notes are original synthesis; resources are links, not mirrors.

## How to use this repo

1. **New to AI Engineering?** Start at `docs/00-prerequisites/` and go in order — each folder builds on the last.
2. **Need a refresher on one concept?** Jump straight to the relevant `docs/` file — each is self-contained with definitions, tables, and comparisons.
3. **Want to go deeper on a topic?** Check the matching file in `resources/` for free courses, papers, and tools.
